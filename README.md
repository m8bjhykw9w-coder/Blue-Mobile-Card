# Blue Mobile — Card Receipt Generator (مولّد وصولات الكروت)

تطبيق ويب متكامل وجاهز للإنتاج مصمم خصيصاً لمتجر **Blue Mobile (الخمس - الحارة)** لتوليد وطباعة وتصدير وصولات كروت الشحن المسبقة الدفع، كروت الإنترنت، واشتراكات المنصات التعليمية على طابعات الكاشير الحرارية المحمولة مقاس **58mm** و **57mm**.

---

## 1. المزايا الأساسية (Key Features)

1. **دعم الشركات العشر وفئاتها الرسمية بدقة تامة:**
   - **ليبيانا (Libyana):** `5, 10, 30, 40, 100 د.ل`
   - **المدار (Almadar):** `5, 10, 20, 40, 100 د.ل`
   - **التي تي تي (LTT):** `5, 10, 20, 30, 55, 100 د.ل`
   - **جيجا (Giga):** `5, 10, 30, 50, 65, 100, 120 د.ل`
   - **لينك نت (Link Net):** `5, 10, 40, 50, 100, 200 د.ل`
   - **سكاي نت (Sky Net):** `5, 10, 20, 50, 100 د.ل`
   - **أكاديميا (Academia):** `10, 20, 30, 50, 100, 200 د.ل`
   - **إدراك (Edraak):** `10, 20, 50, 100 د.ل`
   - **واكب (Wakeb):** `5, 10, 50, 100 د.ل`
   - **إشرحلي (Esrahli):** `5, 10, 50, 500 د.ل`

2. **تخطيط حراري هندسي دقيق (58mm / 57mm) مع هامش أيمن فارغ إلزامي (15mm):**
   - العرض الافتراضي للورق هو **58mm** (قابل للتغيير إلى **57mm** من الإعدادات).
   - يتم حجز **15mm فارغ تماماً على الجهة اليمنى** من الوصل (بدون أي نصوص أو شعارات أو فواصل أو حدود) لتعويض إزاحة الطابعات الحرارية المحمولة.
   - منطقة الطباعة الفعلية للمحتوى هي **43mm** (لورق 58mm) أو **42mm** (لورق 57mm).
   - هذا الهامش المليمتري الفارغ محفوظ بشكل متطابق 100% في المعاينة الحية، وفي صورة **PNG**، وفي ملف **PDF**، وفي تخطيط **الطباعة المباشرة**.

3. **حفظ صارم لكود الكرت (Code Integrity):**
   - اتجاه إدخال وعرض الكود `LTR` مع الحفاظ التام على الأصفار اليسرى (Leading Zeros) وجميع الحروف والأرقام كما أُدخلت دون إضافة مسافات أو تعديل.
   - يُعرض رقم الكرت دائماً في **سطر واحد فقط** مع تحجيم تلقائي ذكي للخط في حال إدخال أكواد طويلة جداً لمنع الالتفاف أو الاقتصاص.

4. **دعم إدخال عدة كروت في الجلسة (Multiple Independent Receipts):**
   - كل كرت يُنتج وصلاً مستقلاً تماماً (صورة PNG مستقلة، ملف PDF مستقل بمقاس 58mm/57mm، وزر طباعة مستقل)، مع إمكانية تصدير جميع وصولات الجلسة دفعة واحدة كملف `ZIP` أو تنزيلها منفردة.

## 2. التشغيل محلياً (Running Locally)

تأكد من وجود **Node.js** (الإصدار 18 أو أحدث)، ثم نفّذ الأوامر التالية:

```bash
# 1. تثبيت الحزم البرمجية
npm install

# 2. تشغيل خادم التطوير المحلي
npm run dev

# 3. بناء نسخة الإنتاج
npm run build

# 4. معاينة نسخة الإنتاج محلياً
npm run preview
```

---

## 3. النشر على منصة Vercel (Deploying to Vercel)

المشروع مهيأ بالكامل للنشر المباشر على **Vercel** (يحتوي على ملف `vercel.json`):

1. ارفع المشروع إلى مستودع **GitHub** الخاص بك.
2. سجّل الدخول إلى [Vercel](https://vercel.com) واضغط على **Add New Project**.
3. اختر مستودع المشروع من GitHub.
4. إعدادات البناء التلقائية (Framework Preset: **Vite**):
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. اضغط على **Deploy** ليتم نشر التطبيق خلال ثوانٍ.
